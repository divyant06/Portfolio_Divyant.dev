## ⚡ Core Architecture & Engineering

This is not a standard template. This portfolio is a digital playground built to break out of the standard web grid, utilizing custom physics engines, WebGL, and Next.js App Router optimizations to create a living, breathing interface.

* 🪐 **The Gravity Pit (Matter.js):** A custom 2D physics engine where the technology stack icons become interactable, rigid bodies reacting to cursor constraints, dragging, and screen boundaries.
* ⌨️ **Interactive 3D Hardware (Spline):** Lazy-loaded (`next/dynamic`), fully interactive 3D components (like the glowing mechanical keyboard) seamlessly embedded into the DOM without sacrificing Core Web Vitals or GPU performance.
* 🌊 **Fluid Shaders & WebGL:** Native HTML5 `<canvas>` environments running custom algorithms to generate interactive, mouse-reactive plasma and light waves.
* 🌍 **Global Network (React Three Fiber):** A WebGL-powered 3D globe visualizing international connectivity and spatial data points.
* 📈 **Programmatic Monetization:** Bulletproof Next.js integration with Google AdSense, handling React Strict Mode double-mounting and hydration states via Server-Side Meta Tags.
* ⚡ **Extreme Performance:** Strict rendering budgets utilizing Turbopack, intersection observers to pause off-screen WebGL contexts, and aggressive caching.

## 💻 Local Development Setup

Want to spin this up locally and play with the Matter.js physics engine?

```bash

git clone [https://github.com/divyant06/Portfolio_Divyant.dev.git](https://github.com/divyant06/Portfolio_Divyant.dev.git)

# 2. Navigate into the directory
cd Portfolio_Divyant.dev

# 3. Install dependencies
npm install
# 4. Start the development server (Turbopack enabled)
npm run dev
```

Navigate to http://localhost:3000 to view the build.
